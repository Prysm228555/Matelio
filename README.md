# Matelio

> Gestion simple et centralisée du matériel pour les associations.

**Matelio** est une webapp destinée aux associations qui souhaitent gérer facilement leur matériel, suivre les stocks, les emprunts et les retours, et garder un historique de l'utilisation de leurs équipements.

L'objectif est de proposer une solution **simple, moderne, accessible et open-source**, adaptée aux petites et moyennes associations.
